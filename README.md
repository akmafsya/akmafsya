## NusaForge Inventory

**An AI-assisted full-stack learning project**

NusaForge Inventory is a portfolio demo for a fictional Malaysian manufacturing company. It includes inventory and raw-material tracking, stock-in and stock-out workflows, supplier records, low-stock alerts, role-aware screens, and responsive layouts.

I am using the project to learn how a React interface, server API, authentication, authorization, and relational data model fit together. I am also experimenting with Codex as a development aid for exploring architecture, implementing features, debugging, and running checks. I review the changes and use them to understand the code and its security trade-offs rather than treating generated code as a black box.

This is a learning project and fictional demonstration, not a production inventory system.
